Sección 01Primeros pasos con Python

Python es hoy el lenguaje más usado en cómputo científico e ingeniería: sintaxis legible, gratuito, y con una comunidad enorme que mantiene librerías maduras para prácticamente cualquier problema numérico. En este curso no vamos a "aprender a programar" en abstracto: vamos a usar Python como una calculadora avanzada para aplicar y verificar los métodos que vemos en el tablero, siempre con las rutinas ya listas de SciPy.

En este curso, Python es una herramienta

No es el objetivo del curso. Para cada método (bisección, Newton, interpolación...) vamos a usar directamente la rutina ya implementada en SciPy, entendiendo qué hace y cómo interpretar sus resultados.

¿Dónde escribimos y corremos el código?

El libro fuente de esta clase muestra Python desde una terminal o desde IPython. En este curso vamos a usar Google Colab: un cuaderno de Jupyter que corre en la nube de Google, sin instalar nada, con las librerías científicas ya preinstaladas y guardado automático en tu Google Drive.

Tour rápido de Colab

Sección 02Python como calculadora

La forma más simple de pensar en Python al comienzo es como una calculadora con esteroides. Los operadores aritméticos son + - * / ** (potencia), y el orden de operaciones es el mismo que aprendiste en el colegio: potencias antes que multiplicación/división, antes que suma/resta. Los paréntesis () fuerzan el orden que quieras.

Pruébalo
(3*4)/(2**2 + 4/2) # potencias y multiplicación primero, luego la suma y la división
Out: 2.0

En Colab/IPython, el símbolo _ guarda el resultado de la última operación ejecutada, útil para encadenar cálculos:

3/4 # Out: 0.75 _ * 2 # Out: 1.5 (usa el 0.75 anterior) _ ** 3 # Out: 3.375 (usa el 1.5 anterior)

El módulo math

Funciones como sin, cos, tan, exp, log y sqrt viven en el módulo math de la librería estándar. Hay que importarlo antes de usarlas:

import math math.sqrt(4) # Out: 2.0 math.sin(math.pi / 2) # Out: 1.0 math.exp(math.log(10)) # Out: 10.000000000000002 (redondeo, ver cap. 9)
⚠️

math.log es el logaritmo natural (base e), no base 10. Para base 10 se usa math.log10. Y 1/0 lanza ZeroDivisionError en vez de devolver infinito.

Tipos de datos numéricos

Python identifica automáticamente el tipo del dato, sin que lo declares tú. Se verifica con la función type():

TipoEjemplotype(x)
int1234int
float3.14float
complex2 + 5jcomplex

Nota: en Python la parte imaginaria se escribe con j, no con i. También existe notación científica: 1e6 equivale a 1 000 000, y 1e-3 a 0.001.

Sección 03Manejo de paquetes

Un paquete (o librería) es código ya escrito por la comunidad que reutilizamos en vez de reprogramar desde cero. Es la razón por la que Python es tan usado en ciencia e ingeniería: casi cualquier problema numérico ya tiene una librería madura resolviéndolo.

pip: el gestor de paquetes
pip install nombre_paquete # instalar pip install --upgrade nombre_paquete # actualizar (o -U) pip uninstall nombre_paquete # desinstalar pip list # ver instalados pip show nombre_paquete # info del paquete

En Google Colab casi todo lo que usamos en el curso ya viene preinstalado, así que rara vez vamos a necesitar pip install.

Las tres librerías del curso

import numpy as np # arreglos y álgebra lineal básica import scipy # métodos numéricos ya implementados from scipy import linalg # álgebra lineal avanzada (sistemas, factorizaciones) import matplotlib.pyplot as plt # gráficas de funciones y resultados
numpy
Arreglos y operaciones vectoriales/matriciales. np.array([1,2,3]), np.linalg.norm(v).
scipy
Métodos numéricos ya implementados y listos para usar. scipy.optimize.bisect.
matplotlib
Gráficas de funciones y convergencia de errores. plt.plot(x, y); plt.show().

Sección 04Jupyter Notebook / Colab a fondo

Un notebook no se ejecuta de una vez de arriba a abajo como un script: se ejecuta celda por celda, en el orden en que tú decidas correrlas. Eso es justo lo que hace a Jupyter/Colab tan cómodo para experimentar: puedes correr una celda, revisar el resultado, y volver a correr solo esa celda si algo salió mal, sin repetir todo el cuaderno.

Por qué importa el orden de ejecución

Si una celda usa una variable que se define en una celda de más abajo (que todavía no has corrido), Python va a lanzar un NameError, aunque esa celda "se vea" más arriba en el cuaderno. Lo que importa es el orden en que ejecutaste, no el orden en que están escritas.

Sección 05Expresiones lógicas y operadores

Una expresión lógica es un enunciado que puede ser verdadero o falso (por ejemplo, a < b). En Python el resultado es del tipo bool: True o False.

Operadores de comparación

Con a = 4 y b = 2:

OperadorSignificadoEjemploResultado
>mayor quea > bTrue
>=mayor o iguala >= bTrue
<menor quea < bFalse
<=menor o iguala <= bFalse
!=distintoa != bTrue
==iguala == bFalse

Operadores lógicos

Combinan dos expresiones lógicas P y Q:

OperadorResultado
P and QTrue solo si P y Q son ambas True
P or QTrue si al menos una de P, Q es True
not PTrue si P es False, y viceversa

El orden de operaciones combina los tres tipos: primero la aritmética, luego las comparaciones, y al final los operadores lógicos. Aun así, conviene usar paréntesis para que la intención del código quede clara.

Pruébalo

¿Hay más de 100 000 segundos en una quincena (14 días)?

(14 * 24 * 60 * 60) > 100000 # 14 días en segundos, comparado contra 100 000
Out: True
⚠️

Python acepta cosas como 3 and 1 (cualquier número distinto de 0 se trata como verdadero), pero no hay que apoyarse en eso. Para que el código sea legible, siempre usa True/False explícitos en vez de números sueltos.
